# Food.com Recommender Systems (Computación Social y Personalización)

Este repositorio contiene el código y el informe del trabajo de la asignatura **Computación Social y Personalización (Grado en Ciencia de Datos)**.

El objetivo es comparar técnicas de recomendación sobre el dataset **Food.com – Recipes and User Interactions**.

## Dataset

Este proyecto usa el dataset de Food.com (Kaggle):
https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-user-interactions

Por tamaño/licencia, los ficheros originales NO se incluyen en el repositorio.

### Dónde colocar los ficheros
Coloca los CSV descargados en:

- `data/raw/interactions_train.csv`
- `data/raw/interactions_validation.csv`
- `data/raw/interactions_test.csv`
- (opcional) `data/raw/RAW_recipes.csv`

### Samples
En `data/sample/` se incluye un subconjunto pequeño para poder ejecutar pruebas rápidas.


## Modelos comparados

- Baseline: predicción por **media** (y baselines adicionales si aplica)

- **KNN Collaborative Filtering**

- **Matrix Factorization (PMF)**

- **Bernoulli Matrix Factorization** (implícito)
